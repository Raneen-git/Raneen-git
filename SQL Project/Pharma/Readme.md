Objective: Optimize a $10M multi-channel marketing budget across face-to-face and digital channels for a newly launched oncology drug.
Tech Stack: PostgreSQL, Advanced Window Functions, CTEs, Relational Data Modeling.

**1. Data Arch and Schema**

-- 1. Create Tables with Relational Constraints
DROP TABLE IF EXISTS prescriptions CASCADE;
DROP TABLE IF EXISTS sales_calls CASCADE;
DROP TABLE IF EXISTS digital_interactions CASCADE;
DROP TABLE IF EXISTS physicians CASCADE;

CREATE TABLE physicians (
    surrogate_key SERIAL PRIMARY KEY,
    physician_id INT,
    first_name VARCHAR(50),
    last_name VARCHAR(50),
    specialty VARCHAR(50),
    region VARCHAR(20),
    segment VARCHAR(20),
    start_date DATE,
    end_date DATE,
    is_current INT
);

CREATE TABLE prescriptions (
    prescription_id SERIAL PRIMARY KEY,
    physician_id INT,
    prescription_month DATE,
    trx_count INT,
    revenue NUMERIC(10, 2)
);

CREATE TABLE sales_calls (
    call_id SERIAL PRIMARY KEY,
    physician_id INT,
    call_date DATE,
    rep_id INT,
    outcome VARCHAR(30)
);

CREATE TABLE digital_interactions (
    interaction_id SERIAL PRIMARY KEY,
    physician_id INT,
    interaction_date DATE,
    channel_type VARCHAR(30),
    engagement_score INT
);

**2. Insights and Queries**
Analysis A: The Sales VP wants a report showing each physician's performance. For every month they wrote prescriptions, calculate:

The total revenue for that month.

A running total of revenue generated by that specific physician over time (so we can see their growth trajectory).

A ranking of months for each doctor, where their highest-earning month is ranked #1.

SELECT 
    physician_id,
    prescription_month,
    revenue,
    -- 1. Running total per physician ordered by month
    SUM(revenue) OVER(
        PARTITION BY physician_id 
        ORDER BY prescription_month
    ) as running_total_revenue,
    -- 2. Rank of months based on highest revenue
    RANK() OVER(
        PARTITION BY physician_id 
        ORDER BY revenue DESC
    ) as monthly_revenue_rank
FROM prescriptions;

Analysis B : 
The Business Problem
A major pharmaceutical company has launched a new specialized oncology drug. They are marketing to physicians using two main channels: Sales Rep Visits (Face-to-Face) and Digital Marketing (Emails/Webinars). The executive leadership team wants to know:

Which physicians are responding best to which channel?

Are sales reps focusing their efforts on the highest-value doctors (Targeting Efficiency)?

What is the return on investment (ROI) of our marketing spend, and how should we reallocate our budget next quarter?
The Scenario
Each Sales Call costs the company $200 (travel, rep salary, samples).

Each Digital Interaction costs the company $20 (software, content creation).

We want to see total costs vs. total revenue for each doctor in 2025.
Used CTEs and JOINS

Query:
WITH sales_costs AS (
    SELECT 
        physician_id,
        COUNT(call_id) * 200 AS total_sales_rep_spend
    FROM sales_calls
    WHERE outcome = 'Detailed'  -- Only count successful meetings
    GROUP BY physician_id
),
digital_costs AS (
    SELECT 
        physician_id,
        COUNT(interaction_id) * 20 AS total_digital_spend
    FROM digital_interactions
    GROUP BY physician_id
),
revenue_generated AS (
    SELECT 
        physician_id,
        SUM(revenue) AS total_revenue
    FROM prescriptions
    GROUP BY physician_id
)
SELECT 
    p.physician_id,
    p.first_name || ' ' || p.last_name AS physician_name,
    p.segment,
    COALESCE(r.total_revenue, 0) AS total_revenue,
    COALESCE(s.total_sales_rep_spend, 0) AS sales_spend,
    COALESCE(d.total_digital_spend, 0) AS digital_spend,
    (COALESCE(s.total_sales_rep_spend, 0) + COALESCE(d.total_digital_spend, 0)) AS total_marketing_spend,
    -- ROI Calculation
    CASE 
        WHEN (COALESCE(s.total_sales_rep_spend, 0) + COALESCE(d.total_digital_spend, 0)) > 0 
        THEN (COALESCE(r.total_revenue, 0) / (COALESCE(s.total_sales_rep_spend, 0) + COALESCE(d.total_digital_spend, 0)))
        ELSE 0 
    END AS marketing_roi
FROM physicians p
LEFT JOIN revenue_generated r ON p.physician_id = r.physician_id
LEFT JOIN sales_costs s ON p.physician_id = s.physician_id
LEFT JOIN digital_costs d ON p.physician_id = d.physician_id
WHERE p.is_current = 1; -- Pull their latest segment info for reporting
